# Cadastro de Usuários

Sistema de cadastro de usuários desenvolvido em Java, utilizando interface gráfica e integração com banco de dados.

## Tecnologias

* Java
* Java Swing
* JDBC
* MySQL
* NetBeans

## Funcionalidades

* Cadastro de usuários
* Consulta de usuários
* Atualização de dados
* Exclusão de usuários

## Conceitos

* Programação Orientada a Objetos
* CRUD
* JDBC
* SQL
* Integração com banco de dados

## Objetivo

Projeto desenvolvido para aplicação prática de conhecimentos em desenvolvimento de software, Java e banco de dados.
